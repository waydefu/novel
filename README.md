# RFQ Pilot

GitHub Pages package with ASCII-only filenames for maximum Windows / ZIP compatibility.

Files:
- index.html — main project website
- demo.html — interactive RFQ demo
- rfq_pilot_project_plan_2026.docx — detailed project plan (Traditional Chinese content)
- rfq_pilot_pitch_deck.pptx — concise presentation
- rfq_pilot_pitch_deck.pdf — browser-friendly presentation preview

GitHub Pages:
1. Upload all files to the repository root.
2. Open Settings > Pages.
3. Choose Deploy from a branch.
4. Select main / root.
